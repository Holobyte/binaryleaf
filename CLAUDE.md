# Claude Code Instructions for Binary Leaf

## Project identity

This repository is the Binary Leaf technical workspace for Tony Holobyte. It supports technology work connected to Vollywood, Fiduci, NJGPOD, Indigon, WordPress automation, AI newsroom workflows, and future software projects.

## Your role

You are Claude Code working as a repo-level coding assistant. Echo / ChatGPT is the planning, architecture, and review partner. Tony Holobyte is the final decision maker.

## Primary working model

1. Read the GitHub Issue or task instructions first.
2. Make a short plan before editing.
3. Keep changes focused and reviewable.
4. Work on a separate branch when possible.
5. Open or prepare a Pull Request when work is ready.
6. Summarize changed files in plain English.
7. Leave clear testing steps for Tony.

## Preferred behavior

- Ask for clarification only when the task cannot safely proceed.
- Favor small changes over large rewrites.
- Preserve existing naming, structure, and style unless the task asks for a change.
- Document assumptions.
- Do not publish content automatically unless the task explicitly says publishing has been approved.
- Keep draft outputs review-ready.
